# Instrucciones del proyecto

Proyecto de clase: React 19 + Vite, con CSS plano (sin librerías de estilos).

## Estilos

Para cualquier tarea de estilos, CSS, clases, colores, diseño o apariencia,
**leer y seguir `docs/guia-estilos.md`** antes de hacer cambios.

Resumen:
- Solo cambiar CSS y `className`; no tocar la lógica de React.
- Variables en `src/index.css`, clases reutilizables en `src/App.css`,
  estilos propios en `src/components/NombreComponente.css`.
- Diseños de referencia en `docs/referencias/`.
